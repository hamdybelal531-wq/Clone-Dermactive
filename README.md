E-Commerce Frontend Website

A fully responsive e-commerce frontend built with Next.js, React, and Tailwind CSS.
The project includes all core shopping features such as products listing, product details, cart management, and a contact form connected to a fake API using JSON Server.

This project is created to showcase my frontend skills (UI, UX, state management, API integration, responsiveness, and component architecture).

Features

Responsive navigation bar

Shopping cart system using LocalStorage

Products listing & details pages

Image sliders & animations (Framer Motion)

Contact form connected to a fake backend (JSON Server)

Fully responsive design for all devices

Form validation & success/error handling

Fast performance using Next.js App Router

Note: Authentication & Payment systems are not included but will be added in the future.
